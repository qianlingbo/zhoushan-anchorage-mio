安装灌门航窗查询

安装后，Codex、Hermes、OpenClaw 等 Agent 可按日期直接读取 2026 年大型船舶允许过灌门时间。Skill 使用公开 JSON，不需要密钥。

下载 Skill ZIP ↓
SKILL.md STANDARDNO API KEYASIA/SHANGHAI2026 FULL YEAR

Codex

安装到 Codex 默认个人 Skill 目录。

mkdir -p ~/.agents/skills/guanmen-passage
curl -L https://www.zsagent01.com/guanmen/skill/guanmen-passage/SKILL.md -o ~/.agents/skills/guanmen-passage/SKILL.md

Hermes

Hermes 支持从公开 SKILL.md 地址直接安装。

hermes skills install https://www.zsagent01.com/guanmen/skill/guanmen-passage/SKILL.md --name guanmen-passage

OpenClaw

下载 ZIP、解压，然后作为本地 Skill 全局安装。

unzip guanmen-passage-skill.zip
openclaw skills install ./guanmen-passage --global

按日期直接调用

不安装 Skill 也可直接获取 JSON。把日期替换为 2026 年任意一天；最终允许时段读取 allowedWindows。

GET https://www.zsagent01.com/guanmen/api/2026-09-01.json
