🤖 Agent Skill 安装指南

将舟山锚地供油指数查询能力接入你的 AI Agent（如 Codex 桌面版），无需打开网页，一句话即可查询当前各锚地的 MIO 评分、风浪、能见度及天气预报。

✨ 支持的功能

四个锚地全覆盖 条帚门 · 虾峙门外 · 马峙 · 秀山东
MIO 供油指数 ●适宜 / ●一般 / ●较差 / ●恶劣
分时段精细预报 3 小时一个窗口，最长预报 5 天
风浪 · 能见度 风向风速、波高、能见度一览

📊 MIO 供油指数说明

●适宜（评分 4） ●一般（评分 3） ●较差（评分 2） ●恶劣（评分 1）

🚀 一键安装（推荐）

复制下方链接，粘贴到 Codex（桌面版）或支持自定义 Skill 的 Agent 中即可完成安装：

https://raw.githubusercontent.com/qianlingbo/zhoushan-anchorage-skill/main/SKILL.md

📁 手动安装步骤

第一步：在 Agent 的 skills 目录下创建文件夹
~/.agents/skills/zhoushan-anchorage/

第二步：下载 SKILL.md 和脚本
curl -O https://raw.githubusercontent.com/qianlingbo/zhoushan-anchorage-skill/main/SKILL.md
curl -O https://raw.githubusercontent.com/qianlingbo/zhoushan-anchorage-skill/main/scripts/query.py

第三步：确保 query.py 放在 scripts/ 子目录下

💬 Agent 中如何使用

直接在 Agent 对话中描述你的需求，例如：

"帮我查一下虾峙门外锚地今天下午的供油条件怎么样" "明天早上 8 点适合在条帚门锚地加油吗" "对比一下四个锚地今晚的天气预报"

🖥️ 命令行直接调用

# 全部锚地概览 python3 scripts/query.py # 查询特定锚地 python3 scripts/query.py 虾峙门外锚地 # 锚地 + 时间段 python3 scripts/query.py 虾峙门外锚地 14时
