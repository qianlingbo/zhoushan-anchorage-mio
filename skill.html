MANUAL & CLI

手动安装与命令行调用

mkdir -p ~/.agents/skills/zhoushan-anchorage/scripts
curl -fsSL https://raw.githubusercontent.com/qianlingbo/zhoushan-anchorage-skill/main/SKILL.md -o ~/.agents/skills/zhoushan-anchorage/SKILL.md
curl -fsSL https://raw.githubusercontent.com/qianlingbo/zhoushan-anchorage-skill/main/scripts/query.py -o ~/.agents/skills/zhoushan-anchorage/scripts/query.py
# 全部锚地概览
python3 scripts/query.py

# 查询特定锚地 / 时间段
python3 scripts/query.py 虾峙门外锚地
python3 scripts/query.py 虾峙门外锚地 14时
