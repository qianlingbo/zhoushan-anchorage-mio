# Character assets

The game embeds the Michelle character and the Idle / Walk / Run animation reference
from the Three.js r170 examples. The second model is used only to transfer animation;
its soldier geometry is not displayed in this game.

- Character: Adobe / Mixamo Michelle, distributed as `Michelle.glb` in the official
  [Three.js repository](https://github.com/mrdoob/three.js/blob/r170/examples/models/gltf/Michelle.glb).
- Animation source: Adobe / Mixamo, distributed as `Soldier.glb` in the official
  [Three.js repository](https://github.com/mrdoob/three.js/blob/r170/examples/models/gltf/Soldier.glb).
- [Adobe Mixamo FAQ](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html)
  permits royalty-free character and animation use in personal and commercial games.

These are embedded application assets, not a standalone model / animation library.
Their third-party usage terms apply; they are not relicensed under the project's
source-code license. Terrain, vegetation, buildings and procedural NPCs are generated
by this game's own code. No Nintendo or Abeto assets are included.
