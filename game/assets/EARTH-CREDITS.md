# Earth geography

The opening globe uses **Natural Earth 1:110m land polygons**. The file is stored locally as `earth-land.geojson`; it contains coastlines only, with no administrative borders.

- Official project: https://www.naturalearthdata.com/
- Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
- License: Public domain — https://www.naturalearthdata.com/about/terms-of-use/
- Original cartography: Tom Patterson, Nathaniel Vaughn Kelso, and Natural Earth contributors.

Ocean coloring, biome-inspired land coloring, subtle relief, procedural cloud cover, atmospheric glow, and travel-node graphics are created by this project. They are artistic visualization rather than satellite imagery or a geographic terrain simulation. Travel destinations are continental hubs, not country boundaries.
